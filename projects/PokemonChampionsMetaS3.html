Pokmeon Champions M-B Meta Analysis


An update on the new season M-B of Pokemon Champions. There were a few Pokemon introduced this season that shaked up the meta, most notably: Raichu Y, Swampert, and Staraptor. The analysis defined whether there were more Physical or Special Attackers, the Pokemon and Damage Move Typings, as well as Held Item and Nature usages.


DATA COLLECTION


All data was collected from the in-game battle data for each season. This analysis is focused on Double Battles, the official VGC format. Since this game does not have an API to gather this data, each data point was manually inserted into an excel sheet. No data cleaning or wrangling was needed.
